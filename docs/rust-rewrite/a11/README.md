# A11 threat intelligence adapter candidate

A11 provides native Rust AbuseIPDB, GreyNoise, OTX and URLhaus adapters and the
`register_threat_intelligence` factory seam. It uses accepted Registry,
SearchAdmission, F06 configuration, AdapterHttp, source JSON and charged projection
ports. Engine/domain execution contains no Python interpreter, sidecar or provider
fallback. Full application, MCP and portal composition remains W09 work.

The `cargo xtask check A11` gate binds 419 individual completion cases across
14 exact compiled test identities. It rejects absent, ignored, caseless, altered,
extra and duplicate completion evidence. The preceding 414-case candidate passed
all 17 gate commands, then independent
source review found the credential boundary described below. The revised gate
retains every prior test/case and adds four credential controls plus their joined
child completion. The earlier locked workspace build, strict Clippy, A09, F01
and O06 also passed on that frozen candidate. The frozen evidence records native replay, private
factories and owned cancellation/resource controls. No provider, public search,
production or deployment probe is part of this evidence.

The source inventory contains 32 original test functions, 41 actual parameterized
calls and all 123 passing setup/call/teardown reports. All 58 baseline observations
are mapped, including nested helper results. Another 250 original boundary
observations, three Unicode URL cases and ten representation cases yield 321
complete source observations. Four additional YAML controls compare configuration
entry behavior rather than adapter search results. See [PARITY.md](PARITY.md).

native test/case binding. `oracle-runs-v1.json` separates historical executed
producer hashes and immutable archives from current formatted/styled producers.
Manual producers are optional G08 retirement targets; the native gate reads frozen
JSON and never executes them. Invalid first boundary capture and all failure/guard
provenance remain archived and are not qualified source references.

# A02 package registry adapters

Native PyPI, RubyGems and Docker Hub adapters consume accepted A01 SearchEngine/factory contracts, caller-owned F08 HTTP pools and F10 SearchAdmission. No provider call, deployment or Python runtime dependency occurs in native replay. Baseline is accepted A01 merge `025ab2f2d50febcb573ba62579eecf7e2d07ef3a`.

`corpus.json` contains 122 independently captured source-bound synthetic regression observations, exported before implementation from actual Python adapters via offline MockTransport. Every exchange carries raw response text (retaining numeric lexemes), actual request sequence and normalized output. SHA-256 is fixed by coverage.json and the native gate. `corpus-extra.json` adds 13 independently captured observations for actual Location-header redirects, detail-shape errors, successful duplicates, zero/candidate caps and configured query replacement; the original corpus bytes remain unchanged. Independent review added `corpus-review.json` with 20 separately source-captured raw-byte/whitespace cases; original 135 bytes remain fixed. `corpus-meta.json` adds three separately captured common meta-declaration cases; the initial 155 observations remain unchanged. All 158 unique case IDs must execute. Existing 18 regression functions (including every parametrized Docker Hub form) map in coverage.json. Registration/categories assertions are tested against actual F06 descriptors; executable availability comes from registered factories, not descriptor rewriting.

Replay creates a disposable loopback listener per case and instantiates each real adapter through Registry. It compares status, result URL/title/content/engine/position/score/payload and request method/URL/query/order/count/auth absence and explicit headers. Only latency and transport-dependent exception prose are excluded. Seven exact integration tests and one default-route unit test include supplemental admission denied/unavailable zero dispatch, active-search cancellation and catalog/config checks. Accepted A01 tests remain unchanged.

Explicit empty PyPI/RubyGems URLs fail before network dispatch; their Defaults preserve omitted configuration URLs, while Docker retains its source empty-value fallback. HTML byte decoding preserves libxml2 Latin1 defaults/C1 controls, explicit legacy charset labels and BOM precedence; empty/comment/declaration-only source documents fail. Docker uses Python whitespace semantics including ASCII information separators. PyPI follows redirects only for direct lookup; every non-200 enters separately configured simple-index fallback. HTML anchors are parsed with pinned scraper, href-derived names preserve encounter order/duplicates, configured candidate cap precedes serial details, failed details are skipped without replacement. Exact and fallback identity/content/payload distinctions are retained. RubyGems preserves list/object collection variants, Python numeric display and source scalar/container stringification. Docker Hub preserves registry/tag/digest scope, Unicode casefold, candidate overfetch and stable exact-name/namespace promotion before truncation.

The only dependency change is a direct edge to already-locked encoding_rs 0.8.42 for source HTML charset semantics; no package identity/version/source changes and no aggregate engine/Jev metadata changes. Private shared A01 Python-compatible scalar helpers receive visibility-only changes for reuse. Source shapes and formatting were verified against source observations, including empty Docker Hub mapping/string iterables. Each PyPI HTTP operation receives a fresh configured timeout on the same caller-owned pool. A narrow Session::set_deadline method preserves the fallback session cookie jar, request budget, cancellation and shutdown state across index/detail requests, preserving Python operation semantics. No remaining end-to-end caller deadline exists at the frozen A01 seam; F14 must cap each operation when it adds that context. Native stable classified diagnostics differ from dynamic HTTPX exception wording as in A01; finite-score and F05/F08 resource bounds remain accepted constraints. This package does not claim exhaustive behavior outside captured cases or production availability.

Capture environment was CPython 3.14.7, httpx 0.28.1 and lxml 6.1.1. Exporters check fixed source blob/digest anchors before executing source and preserve the accepted source commit even on a later native HEAD. The isolated exporter is inventoried in coverage.json for G08 deletion. It is optional migration evidence, never called by native tests or mandatory checks. Corpus refresh requires semantic review; do not regenerate it to make a failed test pass. `first-failures.md` retains initial failures and corrections.

Portal impact review: provider-local adapters and optional factory wiring only; shared SearchRequest/SearchResult serialization, filters, policy, cache, HTTP routes and current portal behavior are unchanged. G01 owns full native server/portal integration and all-adapter availability.

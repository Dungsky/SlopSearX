# Proposed bounds and known differences

Reuse the existing 32MiB operation-owned projection/request-output quota and typed F05 finite-score/scalar-text projection. This is not a global RSS or all-legal-source-domain proof. SourceJson has its existing independent input/node/text limits; response bodies, source DOM, transport and generic formatter allocations are not all inside the output quota. Deadline checkpoints bound admitted wire/decode/projection work using existing F08 mechanisms; this explicit native extension is not identical HTTPX timeout phase accounting or a cold latency claim. Diagnostics deliberately redact source/provider/credential values. HeaderValue is sensitive; HTTPX string API-key headers require ASCII, unlike separately owned DeHashed Basic UTF8 input.

HIBP extraction occurs before source latency measurement but is caller-context cancellable/cooperative and emitted output is charged. Email grammar scanning can revisit candidate suffixes; no linear-time CPU claim. Grouped numeric display reuses an existing allocator-backed codec, so do not infer fully charged formatting/RSS from output quota.

IntelX fresh per-request configured deadlines exclude its one source2s delay, while the unchanged absolute caller deadline covers all phases. Caller cancellation drops the owned sleep immediately. AdapterHttp shutdown while sleeping does not currently wake that delay: after the source delay/context ends, Session rejects GET before dispatch. This is a documented lifecycle boundary, not an instantaneous shutdown promise. No detached task or new polling timer is introduced.

Private literal HTTP children clear inherited environment, refuse proxy configuration before loopback dispatch, retain bounded stdout/stderr prefixes losslessly as Base64 on all drain outcomes, require actual wait status/EOF, and join owned listener tasks before result assertions. All data and keys are synthetic. Native runs and resource limits remain unobserved until separately authorized qualification.

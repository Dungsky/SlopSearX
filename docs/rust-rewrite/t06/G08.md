These finite manual reference producers retire under G08 together with the original Python backend after their native contracts are accepted.

Use `capture_guarded.py PRODUCER NEW_OUTPUT` with the pinned CPython3.14.7/FastMCP4.0.11/mcp2.3.0 historical source checkout. It refuses existing output before backend imports, checks source/interpreter/SDK explicitly even with `python -O`, disables bytecode, runs the original loopback/shared-store guards, stages in an exclusive private directory and publishes with `O_EXCL`. Do not run historical producers directly or overwrite an observation to satisfy a comparator.

The original eight producers are excluded only from automatic Ruff rewriting; their bytes and all JSON artifacts are SHA256-bound. Two large raw corpora exceed the generic500KiB hook but remain JSON-validated and native hash-validated. The frozen `validation.json` also retains its captured missing final newline: only automatic EOF rewriting is excluded, while JSON and native hash validation remain enabled. Generated `__pycache__`/`.pyc` is not delivery evidence and is excluded from source inventory. Pre-correction native statuses, failed compile/lint runs, causal mutation failures and exact restorations remain in the parent review receipts; they are not rewritten as passes.
